# LaVenda Tours Website

This is a complete responsive starter website for LaVenda Tours.

## Before publishing
1. Open `script.js`.
2. Replace `27000000000` with the real LaVenda Tours WhatsApp number.
3. In `index.html`, replace the placeholder email and phone number.
4. Replace the Unsplash image URLs with your own tour photos if you have them.
5. Update the tour names, descriptions and prices to match your actual packages.

## How to test
Open `index.html` in a web browser.

## Publishing
Upload `index.html`, `style.css` and `script.js` to a web host. No server/database is required for the current WhatsApp booking form.
